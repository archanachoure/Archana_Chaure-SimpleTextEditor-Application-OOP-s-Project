# Simple Text Editor (Java)

A console-based Simple Text Editor application built in Java using `StringBuffer`. This project demonstrates basic text manipulation operations like adding, deleting, reversing, and clearing text dynamically.

## 🚀 Features
* **Add Text**: Append new strings to the document.
* **Reverse Text**: Invert the current text buffer.
* **Delete Text**: Remove specific parts of the text using start and end indices.
* **Clear Text**: Wipe out the entire text at once.
* **Display Text**: Real-time preview of the document after every operation.

## 🛠️ Tech Stack
* **Language:** Java (JDK 8 or higher)
* **Concepts Used:** Object-Oriented Programming (OOPs), `StringBuffer` for mutable strings, `Scanner` for user input.
